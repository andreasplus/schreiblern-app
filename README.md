# Schreiblern-App

Druckbare zweisprachige Schreiblernseiten (Deutsch und Englisch) als WebApp auf Cloudflare.

Dieser Stand enthält nur das Übergabepaket:

- `docs/BACKLOG.md`: Anforderungen, Prioritäten und Abnahmekriterien.
- `docs/CLAUDE-AUFTRAG.md`: Implementierungsauftrag.
- `docs/UEBERGABE.md`: Beschreibung des Übergabepakets.
- `data/seed-words.json`: 36 Referenzeinträge.
- `reference/`: portable Python-Layoutreferenz, Originalskripte, ABeeZee mit OFL-Lizenz und die Blitz-Beispielseite.

Nicht im öffentlichen Repository: `car.png`, `reference.png` und die 35-seitige Beispiel-PDF, weil für die darin enthaltene Auto-Vorlage kein Nachweis zur öffentlichen Weiterverwendung vorliegt.
